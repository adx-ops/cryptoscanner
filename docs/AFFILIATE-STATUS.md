## How a link goes live (the only path)
1. David applies to the programme and is accepted; the programme issues a tracking link in its dashboard.
2. `npm run affiliate-link -- --card=<slug> --status=accepted --url=<tracking link> --source=<dashboard or acceptance e-mail URL> --note="<who confirmed what, when>"` — writes `links.affiliate` on the card, a changelog entry and the programme's `our_status` with provenance. Refuses placeholders, http links, and a URL before acceptance.
3. `npm run validate && npm run affiliate-status && npm run build` — the card page and /compare now show "Go to <brand> (affiliate link)" with `rel="sponsored"`.
4. After the first attributed click shows in the dashboard: same command with `--status=tracking_tested`; after the first payout: `--status=payment_observed`.
